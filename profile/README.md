# Marifet Labs

**Dijital dünyada uçtan uca marifet.**

Mobil uygulama, web ve yapay zekâ ürünleri geliştiren genç bir mühendis ekibiyiz.
Adımızı Cezeri'nin 1206'da yazdığı *Ustaca Mekanik Aletlerin Marifeti Üzerine Kitap*'tan alıyoruz.

### Yayındaki uygulamalarımız
- **[Huda: Prayer, Quran & AI](https://play.google.com/store/apps/details?id=com.hafizstudios.huda)**: Namaz vakitleri, çevrimdışı Kur'an ve yapay zekâ asistanı
- **[Focus Hero](https://play.google.com/store/apps/details?id=com.developer.focus_hero)**: Pomodoro tekniğini RPG oyunlaştırmasıyla birleştiren verimlilik uygulaması
